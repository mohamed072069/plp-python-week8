PERSONAL MINI-TOOLKIT PLAN

1. Tools

Tool 1: To-Do List
The To-Do List allows the user to add tasks, view all tasks, and manage a simple list of tasks.

Tool 2: Simple Calculator
The Simple Calculator allows the user to perform addition, subtraction, multiplication, and division.

Tool 3: Number Checker
The Number Checker asks the user for a number and tells them whether the number is positive, negative, or zero.
