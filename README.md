# Personal Mini-Toolkit

## What This Toolkit Does

The Personal Mini-Toolkit is a simple Python program that provides three useful tools. The first tool is a To-Do List that allows users to add and view tasks. The second tool is a Simple Calculator that performs addition, subtraction, multiplication, and division. The third tool is a Number Checker that tells the user whether a number is positive, negative, or zero. The program uses a menu so the user can choose which tool to use. The menu continues to appear until the user chooses the Quit option.
